SHAPE AREA & PERIMETER CALCULATOR

About the project:
This is a simple C++ mini project that calculates the area and perimeter of three geometric shapes: Circle, Rectangle, and Triangle.
The project demonstrates important Object-Oriented Programming concepts through a menu-driven console application.

Features:
1. Calculates the area and perimeter of a circle.
2. Calculates the area and perimeter of a rectangle.
3. Calculates the area and perimeter of a triange.
4. Uses inheritance and virtual functions.
5. Demonstrates runtime polymorphism through a base-class pointer.
6. Checks positive dimensions and invalid triangle sides.
7. Provides a simple menu-driven interface.

Technologies Used:
1. Programming language: C++
2. Concets: Inheritance, virtual functions, function overriding, runtime polymorphism, classes, objects, and encapsulation.

How to Run:
1. Open a C++ compiler.
2. Open or paste the code form shape_calculator.cpp.
3.Compile and run the program.
4. Select a shape from the menu.
5. Enter the required dimensions.
6. View the area and perimeter results.

Conclusion:
This project demonstrates how inheritance and runtime polymorphism can be used to calculate the area and perimeter of different shapes through a common interface.
